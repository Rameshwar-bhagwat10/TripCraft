# TripCraft Design System Master Architecture

## Design System Overview
TripCraft's visual design system follows a modern, minimal, light-only SaaS visual identity tailored for premium mobile-first travel experiences.

### Core Foundations
1. **Light Theme Only**: The application background is strictly `#F8FAFC` (Slate-50) with white surface cards (`#FFFFFF`).
2. **Teal Brand Accent**: Primary actions use Teal `#0F766E`.
3. **Plus Jakarta Sans**: Typography scale implemented across Display, Headline, Title, Body, and Label styles.
4. **Phosphor Icons**: Consistent line and filled iconography family.
5. **8-Point Grid Spacing**: Spacing tokens (4, 8, 12, 16, 20, 24, 32, 40, 48, 64).
6. **Subtle Elevation**: Minimal shadows and border radius hierarchy (6, 8, 12, 16, 20, 24, 999).
