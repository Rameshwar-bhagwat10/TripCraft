# TripCraft Color System

## 1. Primary Brand Palette (Teal)
| Name | Hex Value | Purpose & Usage Rules |
| :--- | :--- | :--- |
| **Primary** | `#0F766E` | Primary buttons, active navigation, brand elements, active states. |
| **Primary Dark** | `#115E59` | Pressed button states, high-contrast brand focus. |
| **Primary Light** | `#CCFBF1` | Selected backgrounds, soft brand surfaces, active indicators. |
| **Primary Surface** | `#F0FDFA` | Secondary buttons, selected card backgrounds. |

## 2. Neutral Palette (Slate)
| Name | Hex Value | Purpose & Usage Rules |
| :--- | :--- | :--- |
| **Background** | `#F8FAFC` | Main application background (Light mode only). |
| **Surface** | `#FFFFFF` | Card containers, input backgrounds, dialogs, bottom sheets. |
| **Surface Secondary** | `#F1F5F9` | Secondary cards, chip backgrounds, disabled containers. |
| **Surface Tertiary** | `#E2E8F0` | Disabled buttons, divider lines. |
| **Border** | `#E2E8F0` | Card borders, text field borders, list dividers. |
| **Border Strong** | `#CBD5E1` | Outlined button borders, active input borders. |

## 3. Typography Colors
| Name | Hex Value | Purpose |
| :--- | :--- | :--- |
| **Text Primary** | `#0F172A` | Headings, titles, primary body text (Never use pure black). |
| **Text Secondary** | `#475569` | Subtitles, labels, secondary information. |
| **Text Tertiary** | `#64748B` | Captions, metadata, unselected nav labels. |
| **Text Disabled** | `#94A3B8` | Placeholder text, disabled button labels. |

## 4. Semantic Feedback & Accents
| Name | Hex Value | Usage |
| :--- | :--- | :--- |
| **Success** | `#16A34A` / `#DCFCE7` | Success badges, confirmation toasts. |
| **Warning** | `#D97706` / `#FEF3C7` | Warning notifications, alerts. |
| **Error** | `#DC2626` / `#FEE2E2` | Error state indicators, validation messages, destructive buttons. |
| **Info** | `#2563EB` / `#DBEAFE` | Information badges and notices. |
| **Accent (Travel)** | `#F59E0B` / `#FEF3C7` | Sunshine highlights, ratings, travel recommendations. |
| **AI Accent** | `#7C3AED` / `#F3E8FF` | Reserved exclusively for AI Copilot, AI badges, and AI suggestions. |
